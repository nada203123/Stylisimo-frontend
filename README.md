 # 👗 Stylisimo Frontend
Stylisimo est une application web e-commerce dédiée à la vente de vêtements.  
Le frontend, développé avec **Angular**, offre une interface utilisateur moderne, responsive et intuitive permettant aux clients de parcourir les produits, gérer leurs favoris, leur panier et passer des commandes en toute simplicité.

## 🧩 Pile technologique
- Framework : Angular

- Langage : TypeScript
  
- Style : CSS / Angular Material

- Gestion des dépendances : npm

- Communication avec l’API : REST (HTTPClient)

- Gestion de version : Git / Bitbucket

## 🚀 Fonctionnalités principales
- Authentification des utilisateurs : inscription, connexion, vérification de compte, mot de passe oublié et réinitialisation via OTP et e‑mail.
  
- Consultation des produits : liste des produits, filtrage par genre (homme, femme, garçon, fille) et par catégories/sous‑catégories (pantalons, chemises, etc.).
  
- Gestion du panier : ajout, modification, suppression des produits dans le panier et calcul du total.
  
- Gestion des favoris : ajout et consultation des produits favoris pour faciliter les futurs achats.
   
- Passage de commande et suivi de la validation de la commande.
  
- Interface administrateur (via le backend) pour la gestion des produits, catégories et commandes.
